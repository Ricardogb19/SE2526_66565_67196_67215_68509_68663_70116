# Use Cases

## Use case diagram: Resource Management.

### Use case 1: Mine resources

Description: The player initiates the extraction of raw materials using drills placed on resource tiles. This process provides the materials needed for all production and defenses.

Primary Actor: Player.

Secondary Actor: None.

### Use case 2: Transport materials

Description: After mining the player sets up conveyor belts and junctions to move resources across the map, towards the player's core.

Primary Actor: Player.

Secondary Actor: None.

### Use case 3: Store resources

Description: The game automatically deposits transported materials into containers, or core storage once they reach designated limit points. The player indirectly influences this process by ensuring proper routing.

Primary Actor:  Game engine.

Secondary Actor: Player.

### Use case 4: Refine materials

Description: The player uses specialized buildings like smelters to convert raw materials into advanced components.

Primary Actor: Player

Secondary Actor: None.

### Use case 5: Allocate resources

Description: The player directs stored or refined materials, using conveyor belts, to specific destinations such as factories or turrets. 

Primary Actor: Player

Secondary Actor: None
